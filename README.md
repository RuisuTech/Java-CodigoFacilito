# Java - Codigo Facilito

Proyecto de aprendizaje de Java basado en el curso de **Codigo Facilito**. Contiene los fundamentos esenciales para aprender Java desde cero.

## Estructura

| Carpeta | Tema |
|---|---|
| `HolaMundo/` | Estructura basica de un programa Java |
| `Tipos-de-Datos/` | Variables, tipos primitivos, comentarios y constantes |
| `Operadores/` | Aritmeticos, asignacion y casting de tipos |
| `OperadoresLogicos/` | AND (`&&`), OR (`\|\|`), NOT (`!`) |
| `OperadoresRelacionales/` | Comparaciones: `>`, `>=`, `<`, `<=`, `==`, `!=` |
| `OperadorTernario/` | Condicionales abreviados (if-else compacto) |

## Como compilar y ejecutar

```bash
# Compilar
javac Carpeta/Archivo.java

# Ejecutar
java Carpeta.Archivo
```

Ejemplo:
```bash
javac HolaMundo/HolaMundo.java
java HolaMundo.HolaMundo
```
